# python-youtube-to-mp3-converter
A simple script to convert a YouTube video in a mp3 file


## How to use
1. Ensure that ffmpeg is installed on your machine. See guide [here](https://video.stackexchange.com/questions/20495/how-do-i-set-up-and-use-ffmpeg-in-windows).
2. Install the required library using `pip install -r requirements.txt`
3. Run app with ` python run.py`.
4. Enter video `url`.
5. Enter directory you wish to save your file after it finishes downloading or leave empty to save file in your default working directory.
